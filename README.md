# Customer Churn Prediction

## Project Overview

This project uses machine learning to predict customer churn based on customer data. It explores customer information, prepares the dataset, and builds machine learning models to identify customers who may leave a service.

## Objectives

- Analyze customer data using exploratory data analysis.
- Clean and prepare the dataset for machine learning.
- Train machine learning models for churn prediction.
- Evaluate model performance using suitable metrics.

## Technologies Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Files

- `customer_churn_prediction_final.ipynb` — notebook containing the analysis and machine learning workflow.
- `telecom_churn_dataset_cleaned.csv` — cleaned dataset used by the project.
- `requirements.txt` — Python dependencies.
- `.gitignore` — files excluded from Git tracking.

## How to Run

1. Clone this repository.
2. Install the required libraries using `pip install -r requirements.txt`.
3. Open Jupyter Notebook.
4. Open `customer_churn_prediction_final.ipynb`.
5. Ensure the CSV dataset is in the expected location and run the notebook cells in order.
